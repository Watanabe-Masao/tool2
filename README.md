## クイックスタート

### 必要要件

- Node.js 18+
- Python 3.11+
- Firebase プロジェクト

### フロントエンド起動

```bash
cd frontend
npm install
npm run dev
```

ブラウザで `http://localhost:5173` にアクセス

### バックエンド起動

```bash
pip install -r requirements.txt
python app.py
```

APIは `http://localhost:8000` で起動

## 主な機能

| 機能 | 説明 |
|------|------|
| **Excelテンプレート生成** | 36店舗への商品配分表を自動作成 |
| **5ステップワークフロー** | 店着日 → 帳合先 → 商品情報の直感的なUI |
| **モバイル対応** | レスポンシブUI、タッチ最適化 |
| **Firebase認証** | Googleアカウントでセキュアにログイン |
| **オフライン対応** | IndexedDBでローカルデータ保存 |
| **PDFプレビュー** | ブラウザで配分表をプレビュー |
| **メール送信** | Resend APIでExcel添付メール送信 |
| **オートコンプリート** | 過去の入力履歴から自動補完 |

## デプロイ

### フロントエンド (Firebase Hosting)

```bash
cd frontend
npm run build
firebase deploy --only hosting
```

### バックエンド (Render.com)

GitHubリポジトリを接続し、`render.yaml`で自動デプロイ
