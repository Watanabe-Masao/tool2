# プロジェクト全体像

## 📋 基本情報

**プロジェクト名**: 配分表テンプレート作成ツール
**バージョン**: 3.0.0 (リファクタリング中)
**最終更新**: 2025-01-24
**ステータス**: 🟡 モバイル版開発中 → PC版改善予定

---

## 🎯 プロジェクト目的

### ビジネス目標
1. **効率化**: 店舗への商品配分作業の自動化
2. **精度向上**: データに基づく配分計画の最適化
3. **分析強化**: 配分実績の蓄積と活用

### ユーザー
- **主要**: 小売チェーンのバイヤー（モバイル利用中心）
- **補助**: 本部管理者（PC利用）

---

## 🏗️ システム構成

### 技術スタック

#### フロントエンド
- **Framework**: React 18 + TypeScript
- **UI**: Material-UI (MUI) + Ionic Framework
- **State**: React Hook Form + Context API
- **Data Fetching**: 将来的にReact Query導入予定
- **Build**: Vite

#### バックエンド
- **Framework**: FastAPI (Python 3.11)
- **Excel**: openpyxl
- **PDF**: LibreOffice
- **Email**: Resend API

#### データベース
- **主DB**: Firestore (リアルタイム、オフライン対応)
- **分析**: BigQuery (将来実装予定)
- **キャッシュ**: ブラウザ IndexedDB

#### インフラ
- **Frontend**: Firebase Hosting (PWA)
- **Backend**: Render
- **CI/CD**: GitHub Actions

## 🔑 主要機能

### 既存機能
1. **注文作成**: 5ステップのフォーム
2. **配分計画**: 36店舗への数量配分
3. **テンプレート生成**: Excel/PDF出力
4. **履歴管理**: オートコンプリート、プリセット
5. **オフライン対応**: IndexedDB同期

### 実装予定機能
1. **配分実績管理** (Phase 4)
   - 計画 vs 実績の記録
   - 差異分析
   - 品質・コスト管理

2. **データ分析** (Phase 4)
   - KPIダッシュボード
   - 商品/店舗パフォーマンス分析
   - トレンド可視化

3. **AI予測** (Phase 5)
   - 需要予測
   - 最適配分提案
