# Google OAuth設定ガイド

## 「このアプリは Google で確認されていません」エラーの解決方法

このアプリはGmail APIを使用してメール送信機能を提供しています。Gmail APIは機密スコープに分類されるため、Google Cloud Consoleで適切な設定が必要です。

## 使用しているスコープ

- `https://www.googleapis.com/auth/gmail.send` - メール送信
- `https://www.googleapis.com/auth/gmail.compose` - メール作成

## 開発・テスト環境での設定

### 1. テストユーザーの追加（推奨）

1. [Google Cloud Console](https://console.cloud.google.com) にアクセス
2. プロジェクト「haibun-distribution」を選択
3. 左メニューから「APIとサービス」→「OAuth同意画面」に移動
4. 公開ステータスが「テスト」になっていることを確認
5. 「テストユーザー」セクションまでスクロール
6. 「+ ADD USERS」ボタンをクリック
7. 使用するGoogleアカウントのメールアドレスを入力
   - 例: watanabe.masao0804@gmail.com
8. 「保存」をクリック

**注意**: テストユーザーは最大100名まで追加可能です。テストユーザーとして追加されたアカウントは、警告画面なしでアプリにアクセスできます。

### 2. OAuth同意画面の確認

OAuth同意画面が「テスト」モードになっている場合:
- テストユーザーのみがアプリを使用可能
- 警告画面は表示されますが、「詳細」→「安全でないページに移動」で続行可能（テストユーザー以外）

## 本番環境での設定

本番環境で一般ユーザーに公開する場合は、Googleアプリ検証プロセスが必要です。

### 必要な手順

1. **OAuth同意画面を「本番」に変更**
   - Google Cloud Console → OAuth同意画面 → 「本番環境にプッシュ」

2. **検証に必要な情報を準備**
   - アプリ名: 配本管理システム（または適切な名前）
   - ユーザーサポートメール
   - デベロッパー連絡先メール
   - アプリのホームページURL
   - プライバシーポリシーURL（必須）
   - 利用規約URL（推奨）

3. **プライバシーポリシーの作成**

   最低限、以下の内容を含める必要があります:
   - どのデータを収集するか（Gmailアカウント情報、メールアドレス）
   - データの使用目的（メール送信のため）
   - データの保管方法
   - データの削除方法
   - 連絡先情報

4. **検証申請の提出**
   - OAuth同意画面で「検証の申請」をクリック
   - 必要な情報を入力
   - アプリのスクリーンショットやデモ動画を提供
   - 審査には通常2-4週間かかります

### 検証申請時のチェックリスト

- [ ] OAuth同意画面の情報が完全に入力されている
- [ ] プライバシーポリシーが公開されている
- [ ] アプリのホームページが存在する
- [ ] 使用するスコープが最小限に抑えられている
- [ ] スコープの使用目的が明確に説明されている
- [ ] アプリの機能を説明するスクリーンショット/動画がある

## よくある質問

### Q: テストユーザーを追加したのに警告が出る
A: ブラウザのキャッシュをクリアするか、シークレットモードで再試行してください。また、追加したメールアドレスと実際にログインしているアカウントが一致しているか確認してください。

### Q: 検証なしで「詳細」→「続行」で使えますか？
A: テストモードでは可能ですが、本番環境では推奨されません。ユーザーに不安を与える可能性があります。

### Q: スコープを減らせますか？
A: `gmail.send`は既に最小限のスコープです。メール送信機能を提供するには、このスコープが必要です。

### Q: 検証プロセスはどのくらい時間がかかりますか？
A: 通常2-4週間ですが、追加情報の要求などがあると長くなる場合があります。

## トラブルシューティング

### エラー: "Access blocked: This app's request is invalid"
- OAuth同意画面の設定が完了していない可能性があります
- 承認済みドメインにアプリのドメインが追加されているか確認

### エラー: "The developer hasn't given you access to this app"
- テストユーザーリストに追加されていない
- OAuth同意画面がテストモードになっている

### エラー: "This app is blocked"
- プロジェクトのクォータが超過している可能性
- Google Cloud Consoleでプロジェクトのステータスを確認
