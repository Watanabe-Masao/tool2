### 主要コンポーネント

| ディレクトリ | 役割 | 主なファイル |
|-------------|------|-------------|
| `pages/` | ページコンポーネント | NewOrderPage, AllocationHistoryPage |
| `components/forms/` | フォーム入力 | ProductFormCard, StoreAllocation |
| `components/modals/` | モーダル | ProductPresetModal, PDFPreviewModal |
| `hooks/` | ビジネスロジック | useOrderSubmit, useTemplateGeneration |
| `services/firebase/` | Firebase操作 | config, firestoreService |
| `services/firestore/` | データ永続化 | リポジトリパターン |
| `stores/` | 状態管理 | orderFormStore |

## データベース設計

### Firestore コレクション

```
firestore/
├── users/
│   └── {userId}/
│       ├── profile (ドキュメント)
│       └── settings (ドキュメント)
│
├── orders/
│   └── {orderId}/
│       ├── createdAt
│       ├── deliveryDate
│       ├── supplier
│       ├── products[]
│       └── allocations{}
│
├── autocomplete/
│   └── {type}/           # suppliers, products, origins
│       └── {value}
│
├── productHistory/
│   └── {historyId}/
│       ├── name, origin, spec
│       ├── pinned, pinOrder
│       └── createdAt
│
└── storeSettings/
    └── {storeId}/
        ├── category
        ├── enabled
        └── order
```

### IndexedDB スキーマ (Dexie)

```typescript
// オフライン対応用のローカルDB
orders: '++id, deliveryDate, supplier, createdAt'
productHistory: '++id, name, supplier, createdAt'
drafts: '++id, step, updatedAt'
syncQueue: '++id, action, data, timestamp'
```

## セキュリティアーキテクチャ

```
┌─────────────────────────────────────────────────────────────────┐
│                         認証フロー                               │
│                                                                  │
│   User ──→ Firebase Auth ──→ ID Token ──→ Frontend              │
│                                    │                             │
│                                    ▼                             │
│                           Firestore Rules                        │
│                           (ユーザーベースアクセス制御)             │
└─────────────────────────────────────────────────────────────────┘

Firestore Security Rules:
- 認証済みユーザーのみ読み書き可能
- ユーザーは自分のデータのみアクセス可能
- 管理者権限は別途設定
```
